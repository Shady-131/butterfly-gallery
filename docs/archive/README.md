# Archive

These files are historical notes from the initial build of Butterfly Gallery —
implementation summaries, change logs, and "transformation complete" reports.

They are preserved for reference but are **not** kept up to date. For current
documentation, see the guides in [`../`](../).

- `START_HERE.md`, `COMPLETION_SUMMARY.md`, `IMPLEMENTATION_SUMMARY.md`, `IMPLEMENTATION_REPORT.md` — build status reports
- `CHANGES.md` — list of files added/changed during the initial build
- `SOCIAL_PAYMENT_UPDATE.md` — notes from the TikTok/InstaPay integration
- `DOCUMENTATION_SUITE.md`, `DOCS_INDEX.md` — earlier documentation indexes (superseded by `../README.md`)
